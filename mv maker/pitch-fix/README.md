# pitch-fix

ガイドボーカルに合わせて、自分の歌の**音程だけ**を直すツール。
リズム・声質・ビブラートはそのまま残ります。

普通のオートチューンは「今出している音に一番近いスケール上の音」へ吸着させるので、
狙った音から半音以上ずれていると**違う音に引き寄せられて**しまいます。
このツールはガイドボーカルから目標のピッチ曲線を直接取るため、ずれ幅が大きくても
正しい音へ引っ張れます。

音声はすべてこの PC の中だけで処理され、外部に送信されません。

---

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方 A — ブラウザで録音しながら

```bash
python server.py
```

ブラウザが開くので、画面の 4 ステップに従います。

1. **ガイド音源を読み込む** — 伴奏なし・ボーカルのみの音源
2. **ガイドを聴きながら歌う** — 3 秒カウントのあと録音開始
3. **直し方を決める** — 補正の強さなど
4. **結果を聴く** — 補正前と聴き比べ、WAV でダウンロード

> **ヘッドホンを必ず着けてください。** スピーカーだとガイドの音がマイクに回り込み、
> ピッチ解析が狂います。

録り直しは何度でもできます。設定を変えて補正だけやり直すこともできます(録音は不要)。

## 使い方 B — 録音済みファイルをコマンドラインで

```bash
python -m pitchfix.cli guide.wav take.wav -o fixed.wav
```

```bash
python -m pitchfix.cli guide.wav take.wav --strength 0.7 --vibrato-keep 0.5
```

主なオプション:

| オプション | 意味 | 既定 |
|---|---|---|
| `--strength` | ガイドへの追従度 0.0–1.0 | 0.85 |
| `--vibrato-keep` | 自分の細かい揺れを残す度合い 0.0–1.0 | 1.0 |
| `--retune-ms` | 補正が追従する速さ(ms) | 80 |
| `--max-shift` | 動かす上限(半音) | 7 |
| `--f0-method` | `dio`(速い)/ `harvest`(高精度) | dio |
| `--offset` | 録音の遅れの初期値(秒) | 0 |

## パラメータの選び方

**補正の強さ (`strength`)**
ガイドの音程にどれだけ寄せるか。1.0 は完全一致しますが機械的になります。
0.7〜0.9 が自然です。まず 0.85 で試してください。

**自分の揺れを残す (`vibrato_keep`)**
ここがこのツールの肝です。歌の音程は

```
歌の音程 = ゆっくりした成分(どこで音を取っているか) + 速い揺れ(ビブラート・しゃくり)
```

に分解できます。補正はゆっくりした成分にだけかかり、速い揺れはこの値の分だけ
そのまま残ります。だから「音程は合ったのに歌が平坦になった」が起きにくい。

- `1.0`(既定): 自分の歌い方をそのまま残す
- 下げる: 意図しない震え・ふらつきも一緒に抑える

**追従の速さ (`retune_ms`)**
短いほど音の変わり目でカチッと決まり、長いほど人間らしくぬるっと動きます。

**動かす上限 (`max_shift`)**
安全装置です。ピッチ推定がオクターブを誤検出したときに音が壊れるのを防ぎます。
結果画面で「上限で頭打ちになった割合」が高い場合は、オクターブ違いで歌っていないか、
ガイドが合っているかを疑ってください。

## 仕組み

```
ガイド ──┐
         ├─→ ① F0 推定 ─→ ② 時間合わせ ─→ ③ 目標曲線 ─→ ④ 再合成 ─→ 出力
録音   ──┘
```

1. **F0 推定** (`analysis.py`)
   WORLD の DIO / Harvest + StoneMask で 5ms ごとにピッチを取る。
   オクターブ誤検出は局所メディアンを基準に自動修正。

2. **時間合わせ** (`align.py`)
   まず発音の立ち上がり(リズム)と旋律の上下の形を同時に相関させて全体の
   オフセットを求め、次に MFCC の DTW で歌い出しや伸ばしのズレを吸収する。
   **録音の時間軸は一切いじりません。** 求めるのは「録音の時刻 t のとき、
   ガイドのどの時刻を目標として読むか」という対応表だけです。

   リズムだけで合わせると規則的な旋律では 1 小節ずれた位置にも同じくらい高い
   ピークが立って取り違えるため、旋律の形も併用しています。

3. **目標曲線** (`correct.py`)
   自分の音程をゆっくりした成分と速い揺れに分解し、ゆっくりした成分だけを
   ガイドへ寄せる。ガイドが無声の区間では補正量をなめらかに 0 へ戻す。

4. **再合成** (`synth.py`)
   スペクトル包絡(フォルマント = 声の音色)を**元の F0 で**解析し、合成のときだけ
   F0 を差し替える。だから音程を上下しても声が高いおもちゃ声になりません。
   長い曲でもメモリが破裂しないよう時間方向にチャンク分割し、境界は無声(息継ぎ・
   子音)の位置に寄せて繋ぎ目が聞こえないようにしています。

## 効果の実測

合成した「音程の取れていない歌」(ゆっくりしたドリフト ±0.9 半音 + 音ごとの
ランダムなずれ ±0.8 半音 + テンポのゆらぎ 5〜6% + 出だしの遅れ)を補正し、
**正解の音程と照合**した結果:

| | ずれの中央値 | 半音以内に収まる割合 |
|---|---|---|
| 補正前 | 0.58 半音 | 44% |
| 補正後 | 0.21 半音 | 92% |

残る 0.21 半音はほぼ意図的に残したビブラート成分です。
`vibrato_keep=0` にすると 0.03 半音まで下がります。

処理時間の目安: 88 秒の音声で約 74 秒(実時間の 0.85 倍程度)。

## うまくいかないとき

**「ガイド音源から音程を検出できませんでした」**
ガイドに伴奏が入っています。ボーカルのみの音源を使ってください。
手元にフルミックスしかない場合は、先にボーカル分離(Demucs など)が必要です。

**「ガイドを参照できた割合」が低い**
時間合わせに失敗しています。ガイドの途中から歌った場合は「開始位置」を
正しく入れてください。CLI では `--offset -(開始位置)` です。

**「上限で頭打ちになった割合」が高い**
ガイドとオクターブ違いで歌っている可能性があります。「動かす上限」を上げるか、
ガイドを自分の音域に移調してから使ってください。

**音が荒れる・不自然になる**
ずれ幅が常時 3〜4 半音を超えると音質が落ちます。補正の強さを下げるか、
ガイドを自分の音域に合わせて移調するほうが良い結果になります。

## ファイル構成

```
pitch-fix/
├── server.py            ローカルサーバー(ブラウザ UI 用)
├── static/index.html    録音・設定・結果表示の UI
└── pitchfix/
    ├── params.py        パラメータ定義
    ├── analysis.py      F0 推定・オクターブ修正
    ├── align.py         オフセット推定・DTW
    ├── correct.py       目標曲線の生成(補正の心臓部)
    ├── synth.py         WORLD による再合成
    ├── pipeline.py      全体の流れ
    ├── audio.py         音声ファイルの読み書き
    └── cli.py           コマンドライン入口
```

# CLAUDE.md — かわいいイコライザーMVメーカー

## プロジェクト概要

16:9の画像を複数枚とMP3をアップロードすると、曲のフル尺で「背景イラストのスライドショー + 音に反応するかわいいイコライザー」のミュージックビデオを生成できるブラウザアプリ。

参考動画の仕組み:
- 1280x720 / 30fps
- 背景に16:9のイラストが順番に切り替わる
- 画面下部にイコライザー(ビジュアライザー)が音楽に合わせて動く
- 動画の長さ = 曲の長さ(フル尺)

## 技術方針

- **単一の `index.html`** にHTML/CSS/JSをすべて含める(ビルドツール不使用、ライブラリはCDNのみ)
- ルートに `index.html` を置くこと(Firebase Hosting等でルートURLが正しく動くために必須)
- フレームワークなしのVanilla JS。Canvas 2D + Web Audio API + MediaRecorder
- 完全にクライアントサイドで動作(サーバー送信なし、オフラインでも動く)
- UIはすべて日本語

## コア機能

### 1. 素材の読み込み
- 画像: 複数枚アップロード(PNG/JPG/WebP)。ドラッグ&ドロップ対応、サムネイル一覧で並べ替え・削除可能
- 16:9でない画像は「余白(パステル背景)」または「カバー(はみ出しトリミング)」を選んで自動フィット
- 音声: MP3を1曲アップロード。`decodeAudioData` で長さを取得

### 2. スライドショー
- 曲の長さを画像枚数で等分して自動切り替え(デフォルト)
- オプション: 1枚あたりの秒数を手動指定(最後は末尾でループ or 最終画像で固定)
- 切り替えエフェクト: フェード / スライド / なし から選択

### 3. イコライザー(選択型・ここがアプリの顔)
`AnalyserNode`(fftSize: 256程度)の周波数データを列ごとに割り当てて描画する。スタイルはプリセットとして選択式にし、後から追加しやすいよう **描画関数を1スタイル=1関数** で分離すること。

初期プリセット:
- **♡ドット絵バー**: パステルカラーのドット絵風ハートが縦に積み上がるバー。音量に応じてハートの段数が増減。ハートは小さなピクセルアート(Canvasで直接描画、8x8グリッドの♡パターン)
- **🌸桜の花びらバー**: ドット絵風の桜の花びら(5弁の桜モチーフ、ピンク〜白のパステル)が積み上がるバー。オプションで最上段の花びらがふわっと舞い散るパーティクル演出
- **🐾肉球バー**: ドット絵風の肉球(メインパッド+指パッド4つ)が積み上がるバー。カラーはピンク肉球/白猫/黒猫/三毛から選択
- **丸ドットバー**: まんまるドット
- **★スターバー**: 星形ドット
- **クラシックバー**: 角丸の普通の棒(グラデーション)

**プリセットの実装構造(重要)**: ドット絵モチーフは「8x8(または16x16)のピクセルパターン定義 + 共通の積み上げ描画エンジン」に分離すること。つまり新しいモチーフの追加は `PIXEL_PATTERNS` にパターン配列を1つ足してプリセット一覧に登録するだけで完了する構造にする。パターンは0/1/2などの数値グリッドで定義し、数値ごとにパレットの色を割り当てる(例: 1=メイン色、2=濃い縁取り色)。

共通オプション:
- カラーパレット選択(パステルピンク系 / パステルレインボー / ミント系 / ラベンダー系 / カスタム)
- 表示位置(下部 / 中央 / 上部)、高さ、左右余白
- 背景を少し暗くする「うっすらオーバーレイ」のON/OFF(イコライザーを見やすくするため)
- バーの本数(16〜48程度)、左右対称ミラー表示のON/OFF

### 4. プレビュー
- Canvas上でリアルタイム再生プレビュー(再生/一時停止/シークバー)
- 設定変更は即座にプレビューへ反映

### 5. 動画書き出し(フル尺)
- `canvas.captureStream(30)` + `MediaStreamAudioDestinationNode` を合成し、`MediaRecorder` で **曲の最初から最後までリアルタイム録画**
- コーデックは `MediaRecorder.isTypeSupported()` で判定し、`video/mp4`(対応ブラウザ)→ `video/webm;codecs=vp9` の順にフォールバック。書き出し形式を画面に明示する
- 出力解像度: 1920x1080(デフォルト)/ 1280x720 を選択可
- 書き出し中は進行バー(経過時間 / 曲の長さ)を表示し、タブを閉じないよう注意書きを出す
- 録画中はプレビュー操作をロック。完了後にダウンロードボタン(ファイル名: `equalizer-mv_YYYYMMDD.webm` 等)

## 実装上の注意

- **AudioContextはユーザー操作後に生成/resume** すること(自動再生制限対策)
- 書き出し用とプレビュー用でAnalyserの経路を共有し、二重再生にならない設計にする
- 周波数データは低域に偏るので、バー割り当ては対数スケールにして見た目のバランスを取る
- ドット絵ハートは `imageSmoothingEnabled = false` でカリッとしたピクセル感を出す
- 大きい画像はアップロード時にオフスクリーンCanvasで出力解像度程度に縮小してメモリを節約
- スマホでも一応動くが、書き出しはPC(Chrome推奨)を想定。UIにその旨を記載

## デザインの方向性

- アプリ自体のUIもパステルカラーでかわいく(丸ゴシック系フォント、角丸、やわらかい影)
- ただし操作は迷わないこと優先: 「①画像 → ②曲 → ③スタイル → ④書き出し」のステップ表示

## 開発の進め方(マイルストーン)

1. 画像+MP3読み込み → Canvasにスライドショー表示
2. AnalyserNodeでクラシックバーのイコライザーを重ねる
3. ♡ドット絵バーなどプリセットとカラーパレットを追加
4. MediaRecorderでフル尺書き出し + 進行表示
5. UI仕上げ(並べ替え、オプション類、ステップUI)

各マイルストーンごとに動作確認してから次へ進むこと。
